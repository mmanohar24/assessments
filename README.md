# Assessments

This is where I keep all the projects and assessments I've built, mostly as part of job applications, take-home challenges, and personal practice.

Each folder is a separate project. Feel free to explore any of them.

---

## Projects

### AnswerThis
A research gap finder tool built with Next.js. It helps users identify gaps in existing research by analyzing topics and surfacing what's missing.

### Dodo Payments
A payments-related project built as part of an assessment. Focused on building a clean, functional payment flow.

### Debrief
A design system and spec tool. Built to help teams document and review product decisions in one place.

### Lila Player Journey Tool
A tool built for LILA Games to map and visualize the player journey across different stages of the game experience.

### Linqapp Data Test
A data processing assessment. Built an event reprocessor in Python that takes raw input events and transforms them into a structured output format.

### Restaurant Command Center
A restaurant management dashboard built with React and Vite. Covers table management, orders, and an overview of live restaurant stats.
